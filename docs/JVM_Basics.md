# JVM Basics

## What is JDK, JRE, JVM?

### JVM (Java Virtual Machine)
- **What:** A virtual machine that executes Java bytecode
- **Purpose:** Provides runtime environment to run Java applications
- **Key Feature:** Platform independence - "Write Once, Run Anywhere"

### JRE (Java Runtime Environment)
- **What:** Contains JVM + core libraries
- **Purpose:** Only for running Java applications (not development)
- **Includes:** JVM + necessary classes to run Java programs

### JDK (Java Development Kit)
- **What:** Contains JRE + development tools (compiler, debugger, etc.)
- **Purpose:** For developing Java applications
- **Includes:** JRE + javac (compiler), javadoc, jar, etc.

## Relationship
- JDK = JRE + Development Tools
- JRE = JVM + Core Libraries


## What is Bytecode?
- **What:** Intermediate code generated by Java compiler (.class files)
- **Human-readable?** No - it's machine-readable for JVM
- **Example:** When you compile `Main.java`, you get `Main.class` (bytecode)

## "Write Once, Run Anywhere"
- **Meaning:** Java code compiled once can run on any platform with JVM
- **How it works:**
    1. Write Java code (.java file)
    2. Compile to platform-independent bytecode (.class file)
    3. JVM on any OS (Windows, Mac, Linux) executes the bytecode
- **Benefit:** No need to recompile for different operating systems
